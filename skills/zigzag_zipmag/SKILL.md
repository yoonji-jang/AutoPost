# zigzag_zipmag 스타일 가이드

지그재그 패션 카테고리 블로그/피드 카피를 쓸 때 지키는 톤 규칙.

## 문체
- 짧은 명사구 위주로 조합한다 (완결된 문장보다 리듬감 있는 나열을 우선).
  - 예: "오프숄더인데 격식도" → "오프숄더지만 격식까지" (조사/연결로 대비를 살리는 교정)
- 문장 끝을 단정적으로 맺는다. 과장된 감탄형 어미는 피한다.
- zip_mag(지그재그 매거진) 특유의 트렌디하고 담백한 톤을 유지한다.

## 금지 표현
- "마법", "실화", "인생템", "완전 대박" 등 AI스럽거나 과장된 유행어 금지
- 근거 없는 최상급 표현("최고", "1등") 금지 — 대신 구체적 특징으로 설명

## 출력물
- 네이버 블로그용 본문 1개 (상품 5개를 하나의 글로 엮음)
- 인스타 피드 카피 5개 (상품당 1개, 짧은 캡션)

## 입력
- 상품 데이터(이름, 가격, 카테고리, 상세 설명, 이미지 경로) 5개
- topic (예: "여름 하객룩")
